## Other explicit submission and format requirements

- **Report:** single self-contained HTML; 10-15 printed pages; ordered manager-facing sections; links/name/one-sentence purpose; embedded screenshots. Verified at 12 pages.
- **Slide deck:** self-contained HTML, Reveal.js, 10 slides maximum; understandable story, diagram, screenshots, key numbers. Verified at 9 slides.
- **Repository/reproducibility:** public project repository includes README, source, sample data, tests, locks, workflow, and both deliverables; secrets and runtime data are excluded. Hosted Actions passes. The course-specific timed clean-clone exercise remains the one reproducibility check not measured in this review.
- **Canvas:** the assignment requests the repository link, `report.html`, and `slides.html`. A 2-3 minute demonstration video is optional, not required.

## Recommendations within the chosen scope

1. Keep the no-trial disclosure visible and avoid converting synthetic or historical app evidence into user-impact claims.
2. Use the optional demo video only if you want a human-recorded backup for the local app; it can demonstrate operation and look/feel but cannot establish user impact or replace the staff-run requirement.
3. Before submission, perform the README setup once from a clean clone with the course parent `.env` arrangement, timing the setup and confirming a saved example opens offline. Do not expose the key.
4. Preserve the Phase 4 H02 row as historical holdout evidence and label the Phase 6 H02 result as one targeted regression everywhere.
